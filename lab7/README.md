# Лабораторная работа 7. Рекомендательная система для медиакаталога

**Задача (практика 7).** Разработать рекомендательную систему для медиакаталога.
На реальных данных сравнить три подхода — контентный TF-IDF, коллаборативный SVD
и item-based ALS — с бейзлайном «популярное». Проверить качество топ-K на оценках,
отложенных по времени, и выяснить, как длина истории пользователя влияет на
результат, охват каталога и разнообразие выдачи.

**Результат.** На MovieLens обработано 100 836 оценок от 610 пользователей
по каталогу из 9 742 фильмов. В тесте оценены рекомендации для 116 пользователей.
По NDCG@10 лидирует бейзлайн «популярное» (0,3338), а ALS при близком значении
(0,3282) показала 207 разных фильмов против 71 у бейзлайна. У 88 пользователей
до даты отсечения нет истории, поэтому все модели дали им одинаковую выдачу.
В группе с 20 и более оценками у ALS NDCG@10 составила 0,0767 против 0,0722
у бейзлайна. Интервал разницы включает ноль.

## Запуск

Python 3.12 x64. Датасет скачивается из GroupLens в `data/` при первом запуске.

```powershell
cd lab7
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python recsys.py --dataset movielens --model all --k 5 10 20 --evaluate
```

Для отдельного пользователя можно указать модель и свою папку вывода.

```powershell
python recsys.py --model als --user-id 601 --k 10 --output results/user-601
```

`--data` принимает путь к архиву `ml-latest-small.zip`. Без истории CLI выдаёт
популярные фильмы. При `--evaluate` модели обучаются на ранних 80% оценок,
а сравниваются на поздних 20% в каталоге фильмов, уже имевших оценки на момент
разделения. Порог релевантности — 4 звезды.

- [metrics.csv](results/metrics.csv) — метрики моделей по K и длине истории.
- [recs.json](results/recs.json) — два разобранных примера с релевантными фильмами
  и отметками попаданий. При запуске с `--user-id` сохраняется и выбранная выдача.
- [summary.json](results/summary.json) — параметры разбиения, состав выборок,
  бутстрэп-интервалы и SHA-256 архива.
- `results/*.png` — графики данных, качества ранжирования, сегментов и покрытия.

Источник данных — [MovieLens Latest Small, GroupLens](https://grouplens.org/datasets/movielens/latest/).
