# Задание 1: тематическое моделирование

```powershell
python topic_modeling.py --dataset news --method lda --topics auto --output news_topics
python topic_modeling.py --dataset products --method nmf --topics 15 --output product_categories
python topic_modeling.py --dataset mixed --method both --topics 10 --compare --output mixed
```

| Аргумент | Значение |
|---|---|
| `--dataset` | `news`, `products` или `mixed` (оба корпуса вместе) |
| `--method` | `lda`, `nmf` или `both` |
| `--topics` | число тем или `auto` — подбор по coherence в диапазоне 3..20 |
| `--compare` | сравнить LDA и NMF на одном датасете |
| `--output` | префикс файлов результата |
| `--top-words` | сколько слов показывать в теме, по умолчанию 10 |

## Что получается

| Файл | Что внутри |
|---|---|
| `{префикс}_topics.json` | темы, ключевые слова с весами, coherence, coherence по каждому K |
| `{префикс}_documents_{метод}.csv` | для каждого документа главная тема и доли всех тем |
| `{префикс}_topwords_{метод}.png` | топ-слова по темам столбиками |
| `{префикс}_coherence_{метод}.png` | зависимость coherence от K с отметкой выбранного |
| `{префикс}_documents_{метод}.png` | тепловая карта «документ — тема» и вес тем по корпусу |
| `{префикс}_wordcloud_{метод}.png` | облака слов |
| `{префикс}_compare.png` | темы LDA и NMF рядом |

## Как устроено

Документ новости — заголовок и описание, документ товара — название и описание с карточки.
Слова приводятся к леммам через pymorphy3, выбрасываются стоп-слова и слова короче трёх
букв. Документы, в которых после очистки осталось меньше пяти слов, не участвуют: они
только зашумляют модель.

LDA работает на мешке слов gensim, NMF — на матрице TF-IDF с 1000 признаками. Слова,
встречающиеся в одном документе или больше чем в половине корпуса, отбрасываются при
построении словаря: тем они не образуют.

Подбор `auto` перебирает K от 3 до 20, для каждого обучает модель и считает coherence c_v,
берёт максимум и рисует график. **Максимум не всегда лучший выбор** — на небольших корпусах
метрика поощряет дробление, и K = 18 означает по несколько документов на тему. Смотрите
на график: разумный K там, где кривая выходит на полку.

# Задание 2: кластеризация городов

```powershell
python city_clustering.py --collect
python city_clustering.py --clusters 4 --output cities
```

`--collect` собирает данные: для каждого города ищет в Википедии страницы о его кухне,
качает тексты и считает, на какой доле страниц упомянуто каждое блюдо из `dishes.py`.
Результат ложится в `data/city_dishes.json`, повторный сбор не нужен.

Без сбора берётся `data/demo_city_dishes.json` — набор для прогона без интернета.
Когда используется он, скрипт пишет об этом в первой строке вывода.

| Файл | Что внутри |
|---|---|
| `cities_clusters.json` | разбиение тремя методами, согласие методов, топ-блюда, метрики |
| `cities_clusters.png` | города на плоскости (проекция PCA), цвет — кластер |
| `cities_evaluation.png` | метод локтя и silhouette score |

## Как устроено

Частотность блюда — доля страниц города, где оно упомянуто, всегда в диапазоне [0, 1].
Синонимы сведены вместе: «эчпочмак» и «треугольник» это одно измерение, иначе они
разъедутся. Блюда, которые есть везде (борщ, блины, пельмени), помечены в словаре
и отбрасываются — различающей информации они не несут, а кластеры размывают.

Строки матрицы нормируются по L2. Без этого город, про который нашлось больше страниц,
оказался бы «ближе» ко всем сразу из-за масштаба, а не из-за кухни.

Кластеризация идёт тремя методами: k-means, иерархическая с linkage='ward' и спектральная
на косинусной близости. Согласие методов считается индексом Rand, а не совпадением номеров
кластеров: номера у методов произвольны, и сравнивать их напрямую бессмысленно. Если индекс
близок к 1.0, структура в данных есть; если методы расходятся — результат ненадёжен.

а Петрозаводск отдельно.

# Если что-то не работает

| Симптом | Причина |
|---|---|
| `нет файла ../lab4/output/news.json` | не собраны данные практики 2 |
| Товаров мало, темы бессмысленные | у товаров нет описаний — соберите lab4 заново, паук забирает их с карточки |
| В топе тем служебные слова | пополните `STOPWORDS` в `preprocess.py` своими доменными |
| `ВНИМАНИЕ: это демонстрационный набор` | не запускался `--collect`, города кластеризуются на демо-данных |
| Спектральная кластеризация ругается на связность графа | городов мало и профили непохожи, на результат не влияет |
