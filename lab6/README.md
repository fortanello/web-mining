# Лабораторная работа 6: анализ и семантическая обработка видеоданных

Пайплайн от ссылки на ролик до интерфейса: метаданные, кадры и аудио, объекты
и речь, события с метками времени, группировка по темам, поиск с переходом
на нужную секунду.

**Задача.** Разработать систему автоматического анализа и семантической обработки
видеоданных: сбор с хостингов и локальных файлов, декомпозиция, распознавание
объектов и речи, временные паттерны, тематическая группировка.

**Результат.** Пять выходов задания закрыты: объекты с уверенностями, события как
интервалы времени, статистика по сущностям, интерактивная временная шкала
с переходом по клику, тематические распределения.

# Установка

```powershell
cd C:\projects\web-mining\lab6
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Нужен **ffmpeg** в PATH (`ffmpeg -version`). Веса YOLO и модель Whisper скачиваются
сами при первом запуске.

**Python 3.12.** Под совсем свежие версии нет сборок `torch` и `ctranslate2`,
установка падает с `ResolutionImpossible`. Создавайте окружение явно: `py -3.12 -m venv .venv`.

**torch под свою видеокарту.** Обычный `pip install torch` ставит сборку, которой может
не быть ядер под новую карту: видеокарта видна, а расчёт падает с
`no kernel image is available`. Для карт поколения Blackwell (RTX 50xx, архитектура
sm_120) нужна сборка не ниже CUDA 13:

```powershell
pip install torch torchvision --force-reinstall --index-url https://download.pytorch.org/whl/cu130
py -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_arch_list())"
```

Вторая команда должна показать `True` и архитектуру вашей карты в списке. Пайплайн
проверяет это сам при запуске и, если ядер нет, предупреждает и считает на процессоре,
а не падает на середине.

**Распознавание речи на процессоре.** `ctranslate2`, на котором работает
`faster-whisper`, собран только под CUDA 12 — с torch под CUDA 13 он не находит
нужных библиотек. Для шестёрки роликов это не критично: кадры через YOLO идут
на видеокарте, а речь считается на процессоре ключом `--device cpu` — около
получаса на сто минут звука.

**Smart App Control.** На Windows 11 эта защита блокирует неподписанные библиотеки
и роняет импорт `faster-whisper` ошибкой «Политика управления приложениями заблокировала
этот файл» (виноват PyAV внутри него). Обходить не нужно: PyAV нужен только для чтения
файла с диска, а дорожку читает сам `speech.py` и отдаёт модели готовые отсчёты.

# Запуск

```powershell
py pipeline.py --sources videos.txt --output index.json
py -m uvicorn api:app --reload
```

Затем открыть `http://127.0.0.1:8000`.

| Аргумент | Значение |
|---|---|
| `--sources` | файл со ссылками и путями, по одному в строке |
| `--clusters` | число тематических групп, по умолчанию 5 — ставьте по числу подтем в наборе, иначе кластеров выйдет почти столько же, сколько роликов, и группировка ничего не покажет |
| `--confidence` | порог детектора, по умолчанию 0.35 |
| `--whisper` | размер модели речи: tiny, base, small, medium |
| `--language` | язык речи, по умолчанию ru |
| `--device` | auto, cpu или cuda |
| `--no-speech` | не распознавать речь (громкость считается всё равно) |
| `--force` | пересчитать, игнорируя кэш |

Ссылки впишите в `videos.txt`. По критериям оценки нужно **не меньше пяти роликов**,
желательно на одну тему — иначе группировка не покажет ничего осмысленного.

# Как устроено

**Кэш обязателен.** Результат каждого шага лежит в `data/<id>/`: метаданные, аудио,
кадры, детекции, транскрипт, события. Повторный прогон пропускает готовое — без этого
отладка на пяти роликах заняла бы часы. Пересчитать заново — ключ `--force`.

Скачивание кэшируется так же: ролик ищется по ссылке в сохранённых `meta.json`, поэтому
второй запуск не тянет те же гигабайты. Прерывание на полпути (Ctrl+C) не теряет
скачанное — пайплайн продолжает с тем, что уже собрано, а остановленный ролик попадает
в `skipped`.

**Частота кадров зависит от длительности.** Одинаковая частота для всех роликов —
типичная ошибка: на часовом видео это 3600 кадров. Частота подбирается так, чтобы
выходило около 240 кадров, в пределах от 0.1 до 1 кадра в секунду.

**Событие — это интервал, а не кадр.** Подряд идущие детекции одного объекта
склеиваются в один интервал; допустимый разрыв считается от частоты кадров.
Кроме объектов событиями считаются всплески громкости, сегменты речи и границы сцен.

**Порог детектора 0.35.** При 0.25 на размытых кадрах появляются ложные срабатывания,
при 0.5 теряются объекты на заднем плане. В отчёт идёт распределение уверенностей
по каждому классу, чтобы выбор можно было проверить.

**Пустой транскрипт помечается.** Ноль распознанных слов — это не «нет речи», а сигнал
проверить язык и звуковую дорожку. Предупреждение видно в консоли, в индексе
и на странице.

**Пропущенный ролик не исчезает молча.** Причина пишется в `index.json` в поле
`skipped` и выводится при прогоне.

**Что система не делает.** Она распознаёт объекты и речь, но не оценивает настроение,
внимание или состояние людей в кадре. Такие выводы по лицам не являются научным
результатом, поэтому их нет сознательно.

**Про условия площадок.** Между загрузками стоит пауза, качество ограничено 720p.
Массовый сбор без пауз нарушает правила хостингов.

# Если что-то не работает

| Симптом | Причина |
|---|---|
| `ffmpeg not found` | ffmpeg не в PATH |
| `Политика управления приложениями заблокировала этот файл` | Smart App Control блокирует неподписанный PyAV — пайплайн это обходит, но если заблокирован `onnxruntime`, уберите `vad_filter=True` в `speech.py` |
| `нет index.json` на странице | не запускался `pipeline.py` |
| Транскрипт пуст | не тот язык в `--language`, нет звуковой дорожки или ролик без речи |
| Детекций ноль | слишком высокий `--confidence`, либо в кадре нет объектов из набора COCO |
| Ролик пропущен | причина в `index.json` → `skipped`: приватное видео, геоблок, нет формата |
| Всё считается на процессоре | torch собран без CUDA или без ядер под вашу карту — смотрите строку «Устройство расчёта» при запуске |
| `ResolutionImpossible`, нет сборок `ctranslate2` | слишком свежий Python, нужен 3.12 |
| `no kernel image is available` | сборка torch старше вашей видеокарты, нужна новее CUDA |
| `cublas64_12.dll is not found or cannot be loaded` | `ctranslate2` собран только под CUDA 12 и не видит библиотек от torch с CUDA 13. Лечится `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`, но на картах поколения Blackwell не помогает — считайте речь на процессоре: `--device cpu` |
| 403 Forbidden при скачивании | ролик закрыт или требует входа — замените запасным из `videos.txt` |
| `сцен 0` у ролика | ролик снят одним планом либо порог `SCENE_THRESHOLD` в `decompose.py` слишком высок |
| Группировка выдала один кластер | роликов меньше трёх, делить нечего |
