# Консольное приложение для поиска по Common Crawl

## Автор: студент гр. АСУ8-25-1м Кузнецов Станислав

## Установка

Нужен Python 3.9+.

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py [слова в адресе] [--domain САЙТ ...] [--prefix ПУТЬ] [--text СЛОВО ...]
               [--count СЛОВО ...] [--limit N] [--show-text] [--stats]
```

| Аргумент | Значение |
|---|---|
| `keywords` | Слова, которые должны быть в URL страницы (без учёта регистра). Без них — все страницы сайта |
| `--domain` | Один или несколько сайтов (по умолчанию `pstu.ru`) |
| `--prefix` | Начало пути на сайте, с учётом регистра (например `wiki/Пастернак`) |
| `--text` | Оставить страницы, в тексте которых есть все эти слова |
| `--count` | Посчитать, на скольких страницах и сколько раз встречается каждое слово |
| `--limit` | Сколько результатов показать (по умолчанию 10) |
| `--show-text` | Достать из WARC заголовок и фрагмент текста |
| `--stats` | Распределение найденных страниц по доменам и датам |

## Практика 1

Упоминание — страница, где слово есть в тексте. Индексу нужен сайт, поэтому источники
перечислены в `--domain`. Все четыре запроса собраны в тетрадке `practice1.ipynb`.

```bash
# 1. Пермь и ПНИПУ: страницы с упоминанием, распределение по доменам и датам
python main.py --domain pstu.ru 59.ru properm.ru perm.aif.ru --text Перм* ПНИПУ --stats

# 2. Кафедра ИТАС: упоминания на страницах электротехнического факультета ПНИПУ
python main.py etf --domain pstu.ru --text ИТАС --stats

# 3. МГУ и МФТИ: сколько раз упомянуты в статьях Википедии о московских организациях
python main.py --domain ru.wikipedia.org --prefix wiki/Московский_ --count МГУ МФТИ

# 4. Пастернак и Пермь: контекст упоминания в статьях о Пастернаке
python main.py --domain ru.wikipedia.org --prefix wiki/Пастернак --text Перм*
```

## Как это работает

1. `cdx-toolkit` запрашивает CDX-индексы 16 последних обходов по шаблону `сайт/путь*`.
   Сервер отбирает записи со статусом 200 и типом `text/html` и отдаёт: URL, дату
   архивации, имя WARC-файла и **смещение (offset)** внутри него. Слова в адресе
   приложение проверяет само: фильтры индекса умеют сравнивать только начало адреса.
2. С `--text`, `--count` и `--show-text` страница забирается из WARC запросом
   `Range: bytes=offset-...` и разбирается через BeautifulSoup. В таблице — кусок текста
   вокруг найденного слова, само слово выделено цветом.
3. `tabulate` печатает таблицы.

## Что важно знать

* **CDX-индекс хранит URL, а не содержимое страниц.** Чтобы проверить текст, страницу
  надо скачать. Поэтому с каждого сайта берётся равномерная выборка из `TEXT_LIMIT = 40`
  страниц — это оценка, а не полный подсчёт.
* **Слова в тексте ищутся целиком**, без учёта регистра: `МГУ` не найдётся внутри
  «СамГУПС». Чтобы найти все формы, добавьте `*`: `Перм*` найдёт «Пермь», «Перми»,
  «Пермский».
* **Слова в адресе отбираются перебором**, не больше `SCAN_LIMIT = 5000` записей на сайт.
  Записи идут по алфавиту, поэтому на большом сайте до нужных страниц можно не дойти —
  тогда задайте начало пути через `--prefix`.
* **Всё скачанное сохраняется в `cache.json`.** Повторный запуск той же команды берёт
  данные оттуда, без сети. Чтобы скачать заново, удалите файл.
* **Common Crawl хранит выборку, а не весь сайт**, и она меняется от обхода к обходу.
  Статьи «Юрятин» нет ни в одном из последних обходов.
* **Индекс блокирует за частые запросы.** Не запускайте несколько копий сразу; если
  соединение сбрасывается, подождите.
